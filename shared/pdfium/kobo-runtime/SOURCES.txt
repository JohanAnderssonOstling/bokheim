The Kobo package includes the ARM hard-float glibc runtime from Bootlin's
armv7-eabihf--glibc--stable-2024.05-1 toolchain. These libraries remain separate
from the application executable and can be replaced in .adds/bokheim/runtime.
The package does not replace Kobo firmware libraries.
