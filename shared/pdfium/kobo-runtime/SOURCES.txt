The Kobo package includes a private ARMv7 hard-float glibc 2.23 runtime,
rebuilt with a Linux 2.6.32 minimum kernel ABI. These libraries remain separate
from the application executable and can be replaced in .adds/bokheim/runtime.
The package does not replace Kobo firmware libraries. An ABI note is not a
substitute for physical-device testing of application syscalls and drivers.

glibc: 2.23
