George: FP32 versus INT8

The same Kokoro v1.0 George voice and passage, using the same native speech runtime and British pronunciation data. INT8 is quantized locally from this FP32 model.

INT8 uses Sherpa's upstream dynamic quantization recipe. INT8-MATMUL is a conservative variant that quantizes only matrix operations and keeps convolutions in FP32.

Memory measurement correction: The earlier Python harness used ru_maxrss, which can retain the quantizer launcher's RSS from before exec. Its historical RAM values are superseded by the fresh Rust /proc measurements above. The Python harness now uses /proc counters for future runs.
