Why this follows from the code

Both controls set .selected(selected) and explicitly supply a light resting background and neutral foreground colors.

Button::render selects theme.accent_active for the pressed background of a selected button. Its active style changes the background only. The control’s foreground overrides remain in place.

Warm light source colors: resting #d9e8de; hover #c7ddcf; pressed #34503f. The suggested fix shown here keeps the light selection treatment while pressed.
