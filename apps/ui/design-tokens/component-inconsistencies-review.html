A visual report of duplicated presentation and inconsistent behavior in apps/components. Each comparison shows the current implementation pattern and a proposed shared contract.

Illustrative HTML, not screenshots of GPUI. Differences below are grounded in source code; exact rendering, contrast and runtime behavior still need checking in the app. Proposed APIs are suggestions.

How to read this report

Each “Current” example now names the actual control and where you encounter it. The table in each section maps that control to its shared helper and the page that uses it.

Shared component = code in apps/components/src. Page / caller = code that composes it in the browser or reader. Proposed = a suggested change, not another existing component.

Implementation update · Button consolidation applied

Sheet close controls, reader rail destinations, picture choices and section paging arrows now return the shared Button. Trash selection now uses the toolkit Checkbox. The shared Button preserves explicit accessible names and caller-owned focus handles; duplicate typeface activation handlers were removed.

The “Current” examples below preserve the source-review snapshot from before this change. Part 2 is also implemented for library naming, folder naming, downloads and annotation export: all use dialog_title and dialog_confirm_button. Part 4 now shares the supporting-text style. Part 5 now shares the book metadata presentation while preserving selectable detail text. The earlier HtmlEngine blocker has cleared. cargo check now passes for ui-components, browser-ui and reader-ui. No tests were run.

Suggested consolidation order

1 · Behavior

Accessible names, standalone control focus, and selection interaction states.

2 · Shared presentation

Dialog titles/actions and final platform button colors.

3 · Smaller primitives

Touch targets, muted text styles and equivalent metadata pieces.

Purpose-specific wrappers are useful. Share the implementation behind them when the behavior and appearance should agree; preserve differences that explain context.
