The language-filter finding

Earlier behavior and the approved fill-only change

Compare the earlier A and B: the books change, but the language button looks identical. C shows the implemented change: active fill on the same icon, with no added label. Click a language button to try it.

What this icon does: it filters books by the language recorded in their metadata. It does not translate a book or change the interface language. The existing symbol is retained; fill now indicates that a language filter is active.
